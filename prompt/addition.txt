## OFFLINE-FIRST ARCHITECTURE

### Sync Strategy
```dart
class SyncService {
  // 1. Save to Hive immediately
  Future saveLocal(dynamic data);
  
  // 2. Add to sync queue
  Future addToQueue(SyncTask task);
  
  // 3. Background sync when online
  Future syncToServer();
  
  // 4. Handle conflicts (last-write-wins)
  Future resolveConflicts();
}
```

### Sync Priority
1. High: Sales, Payments, Collection
2. Medium: Expenses, Stock adjustments
3. Low: Reports, Settings

### Conflict Resolution
- Timestamp comparison
- Server wins for master data
- Local wins for transactions (with validation)
