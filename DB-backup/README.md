# DB-backup Folder

This folder is designated for database backup files.

## Purpose
Store all database backup files here for easy access and organization.

## Backup Files
- Backup files will be stored in JSON format
- Timestamped filenames for easy identification
- Contains all Hive database data

## Usage
- Manual backups can be saved here
- Automatic backups from the app will be stored in the application documents folder
- Copy important backups to this folder for safekeeping
