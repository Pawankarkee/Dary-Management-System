# Contributing to Dairy Management System

Thanks for your interest in contributing! We welcome bug reports, improvements, and pull requests.

How to contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature`.
3. Make your changes, include tests where possible.
4. Commit with clear messages and push to your fork.
5. Open a Pull Request describing your changes.

Guidelines
- Write small, focused PRs when possible.
- Run `flutter format` and `flutter analyze` before opening PRs.
- Include tests for new behaviors where practical.

Communication
- For major changes, open an issue first to discuss design and scope.
